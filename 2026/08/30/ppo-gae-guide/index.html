一口气看懂——强化学习PPO中的GAE详解

1. 先搞清楚：GAE 是在估计什么？

在 PPO 里，我们通常要估计优势函数：

At=A(st,at)A_t = A(s_t, a_t) At​=A(st​,at​)

它表示：在状态 sts_tst​ 下采取动作 ata_tat​，比“平均水平”好多少？
如果：

At>0A_t > 0 At​>0

说明这个动作比平均水平好，PPO 倾向于增加它的概率。
如果：

At<0A_t < 0 At​<0

说明这个动作比平均水平差，PPO 倾向于降低它的概率。
但问题是，真实的 A(s,a)A(s,a)A(s,a) 我们不知道，只能用采样数据估计。

GAE，全称 Generalized Advantage Estimation，就是一种又稳又常用的优势估计方法。

2. 一步TD误差

δt=rt+γV(st+1)−V(st)\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t) δt​=rt​+γV(st+1​)−V(st​)

叫做一步 TD 误差，也可以理解为：

当前这一步带来的“惊喜值”或者“修正值”。

我们拆开看。

当前价值网络认为状态 sts_tst​ 的价值是：

V(st)V(s_t) V(st​)

但是实际走了一步之后，我们发现：

  • 当前拿到了奖励 rtr_trt​；
  • 下一个状态 st+1s_{t+1}st+1​ 的价值估计是 V(st+1)V(s_{t+1})V(st+1​)；
  • 但 V(st+1)V(s_{t+1})V(st+1​) 是未来的价值，要折现到现在，所以乘上 γγγ。

因此实际看到的“当前奖励 + 下一状态折现价值”是：

rt+γV(st+1)r_t + \gamma V(s_{t+1}) rt​+γV(st+1​)

于是 TD 误差为：

δt=rt+γV(st+1)−V(st)\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t) δt​=rt​+γV(st+1​)−V(st​)

如果：

δt>0\delta_t > 0 δt​>0

说明：

实际结果比价值网络原来估计得更好。

如果：

δt<0\delta_t < 0 δt​<0

说明：

实际结果比价值网络原来估计得更差。

3. 多步TD误差

最简单的优势估计是：

At≈δtA_t \approx \delta_t At​≈δt​

也就是：

At(1)=rt+γV(st+1)−V(st)A_t^{(1)} = r_t + \gamma V(s_{t+1}) - V(s_t) At(1)​=rt​+γV(st+1​)−V(st​)

这叫一步优势估计。

它的好处是方差比较小，因为大部分信息来自价值网络 VVV。

但问题是：

如果价值网络估计得不准，那么一步估计就会有偏差。

那怎么办？

我们可以多看几步。

比如不只用 rtr_trt​ 和 V(st+1)V(s_{t+1})V(st+1​)，而是用：

rt, rt+1, V(st+2)r_t,\ r_{t+1},\ V(s_{t+2}) rt​, rt+1​, V(st+2​)

得到两步优势估计：

At(2)=rt+γrt+1+γ2V(st+2)−V(st)A_t^{(2)} = r_t + \gamma r_{t+1} + \gamma^2 V(s_{t+2}) - V(s_t) At(2)​=rt​+γrt+1​+γ2V(st+2​)−V(st​)

类似地，三步优势估计是：

At(3)=rt+γrt+1+γ2rt+2+γ3V(st+3)−V(st)A_t^{(3)} = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \gamma^3 V(s_{t+3}) - V(s_t) At(3)​=rt​+γrt+1​+γ2rt+2​+γ3V(st+3​)−V(st​)

你会发现：

  • 看得越远，越接近真实回报；
  • 但看得越远，越依赖实际采样奖励，方差越大。

所以这里有经典的偏差-方差权衡：

方法 偏差 方差
一步 TD，δtδ_tδt​ 较大 较小
多步 TD 较小 较大
完整蒙特卡洛回报 很小 很大

GAE 的目标就是：

在一步 TD 和完整回报之间，做一个可调的平滑折中。

4. n步TD误差公式推导

一步TD优势是：

At(1)=δtA_t^{(1)} = \delta_t At(1)​=δt​

两步TD优势是：

At(2)=rt+γrt+1+γ2V(st+2)−V(st)A_t^{(2)} = r_t + \gamma r_{t+1} + \gamma^2 V(s_{t+2}) - V(s_t) At(2)​=rt​+γrt+1​+γ2V(st+2​)−V(st​)

现在我们尝试用 δtδ_tδt​ 和 δt+1δ_{t+1}δt+1​ 表示它。

已知：

δt=rt+γV(st+1)−V(st)\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t) δt​=rt​+γV(st+1​)−V(st​)

δt+1=rt+1+γV(st+2)−V(st+1)\delta_{t+1} = r_{t+1} + \gamma V(s_{t+2}) - V(s_{t+1}) δt+1​=rt+1​+γV(st+2​)−V(st+1​)

如果直接相加：

δt+δt+1\delta_t + \delta_{t+1} δt​+δt+1​

会得到：

rt+γV(st+1)−V(st)+rt+1+γV(st+2)−V(st+1)r_t + \gamma V(s_{t+1}) - V(s_t) + r_{t+1} + \gamma V(s_{t+2}) - V(s_{t+1}) rt​+γV(st+1​)−V(st​)+rt+1​+γV(st+2​)−V(st+1​)

我们发现V(st+1)V(s_{t+1})V(st+1​)没有正确消掉，所以我们不能直接加，但是如果增加一个系数γ\gammaγ变成：

δt+γδt+1\delta_t + \gamma \delta_{t+1} δt​+γδt+1​

展开：

δt+γδt+1=[rt+γV(st+1)−V(st)]+γ[rt+1+γV(st+2)−V(st+1)]\delta_t + \gamma \delta_{t+1} = \left[r_t + \gamma V(s_{t+1}) - V(s_t)\right] + \gamma \left[r_{t+1} + \gamma V(s_{t+2}) - V(s_{t+1})\right] δt​+γδt+1​=[rt​+γV(st+1​)−V(st​)]+γ[rt+1​+γV(st+2​)−V(st+1​)]

整理：

=rt+γV(st+1)−V(st)+γrt+1+γ2V(st+2)−γV(st+1)= r_t + \gamma V(s_{t+1}) - V(s_t) + \gamma r_{t+1} + \gamma^2 V(s_{t+2}) - \gamma V(s_{t+1}) =rt​+γV(st+1​)−V(st​)+γrt+1​+γ2V(st+2​)−γV(st+1​)

注意+γV(st+1)和−γV(st+1)+\gamma V(s_{t+1})和-\gamma V(s_{t+1})+γV(st+1​)和−γV(st+1​)抵消掉了。

于是得到：

δt+γδt+1=rt+γrt+1+γ2V(st+2)−V(st)\delta_t + \gamma \delta_{t+1} = r_t + \gamma r_{t+1} + \gamma^2 V(s_{t+2}) - V(s_t) δt​+γδt+1​=rt​+γrt+1​+γ2V(st+2​)−V(st​)

这正好就是两步优势：

At(2)=δt+γδt+1A_t^{(2)} = \delta_t + \gamma \delta_{t+1} At(2)​=δt​+γδt+1​

同理，三步优势是：

At(3)=δt+γδt+1+γ2δt+2A_t^{(3)} = \delta_t + \gamma \delta_{t+1} + \gamma^2 \delta_{t+2} At(3)​=δt​+γδt+1​+γ2δt+2​

一般地，n 步优势可以写成：

At(n)=∑l=0n−1γlδt+lA_t^{(n)} = \sum_{l=0}^{n-1} \gamma^l \delta_{t+l} At(n)​=l=0∑n−1​γlδt+l​

5. GAE经典形式公式推导

现在我们知道了，多步优势可以写成：

At(n)=∑l=0n−1γlδt+lA_t^{(n)} = \sum_{l=0}^{n-1} \gamma^l \delta_{t+l} At(n)​=l=0∑n−1​γlδt+l​

但是我们有无数种选择：

  • 一步优势；
  • 两步优势；
  • 三步优势；
  • ……。

GAE 的想法是：

不要只选一个，把它们按指数权重混合起来。

我们想给不同长度的 n 步优势估计赋予不同权重，并且希望这些权重加起来等于 1。

我们有一组估计：

At(1),At(2),At(3),⋯A_t^{(1)}, A_t^{(2)}, A_t^{(3)}, \cdots At(1)​,At(2)​,At(3)​,⋯

想做一个加权平均：

AtGAE=w1At(1)+w2At(2)+w3At(3)+⋯A_t^{GAE} = w_1A_t^{(1)} + w_2A_t^{(2)} + w_3A_t^{(3)} + \cdots AtGAE​=w1​At(1)​+w2​At(2)​+w3​At(3)​+⋯

其中我们希望：

w1+w2+w3+⋯=1w_1 + w_2 + w_3 + \cdots = 1 w1​+w2​+w3​+⋯=1

并且希望：

  • 短步数权重大一些；
  • 长步数权重小一些；
  • 权重衰减快慢可以调。

最自然的一种选择就是指数衰减权重：

wn∝λn−1w_n \propto \lambda^{n-1} wn​∝λn−1

也就是：

w1∝1,w2∝λ,w3∝λ2,w4∝λ3w_1 \propto 1,w_2 \propto \lambda,w_3 \propto \lambda^2 , w_4 \propto \lambda^3 w1​∝1,w2​∝λ,w3​∝λ2,w4​∝λ3

但是这些权重直接加起来不是 1：

1+λ+λ2+λ3+⋯=11−λ1 + \lambda + \lambda^2 + \lambda^3 + \cdots = \frac{1}{1-\lambda} 1+λ+λ2+λ3+⋯=1−λ1​

所以我们需要归一化，将所有系数乘以1−λ1-\lambda1−λ，得到：

wn=(1−λ)λn−1w_n = (1-\lambda)\lambda^{n-1} wn​=(1−λ)λn−1

就有权重和为1：

∑n=1∞wn=1\sum_{n=1}^{\infty}w_n = 1 n=1∑∞​wn​=1

从而得到GAE的一般形式：

AtGAE=(1−λ)[At(1)+λAt(2)+λ2At(3)+λ3At(4)+⋯ ]A_t^{GAE} = (1-\lambda) \left[ A_t^{(1)} + \lambda A_t^{(2)} + \lambda^2 A_t^{(3)} + \lambda^3 A_t^{(4)} + \cdots \right] AtGAE​=(1−λ)[At(1)​+λAt(2)​+λ2At(3)​+λ3At(4)​+⋯]

AtGAE=(1−λ)∑n=1∞λn−1At(n)A_t^{GAE} = (1-\lambda) \sum_{n=1}^{\infty} \lambda^{n-1} A_t^{(n)} AtGAE​=(1−λ)n=1∑∞​λn−1At(n)​

  • 如果 λλλ 很小，更相信短步数优势；
  • 如果 λλλ 很大，更相信长步数优势；
  • 如果 λ=1λ = 1λ=1，几乎等价于完整蒙特卡洛回报；
  • 如果 λ=0λ = 0λ=0，等价于一步 TD。

把上面的式子展开整理后，会得到 GAE 的经典形式：

AtGAE=∑l=0∞(γλ)lδt+lA_t^{GAE} = \sum_{l=0}^{\infty} (\gamma\lambda)^l \delta_{t+l} AtGAE​=l=0∑∞​(γλ)lδt+l​

6. GAE进阶形式公式推导

进一步地，我们把：

At(1)=δtA_t^{(1)} = \delta_t At(1)​=δt​

At(2)=δt+γδt+1A_t^{(2)} = \delta_t + \gamma\delta_{t+1} At(2)​=δt​+γδt+1​

At(3)=δt+γδt+1+γ2δt+2A_t^{(3)} = \delta_t + \gamma\delta_{t+1} + \gamma^2\delta_{t+2} At(3)​=δt​+γδt+1​+γ2δt+2​

At(4)=δt+γδt+1+γ2δt+2+γ3δt+3A_t^{(4)} = \delta_t + \gamma\delta_{t+1} + \gamma^2\delta_{t+2} + \gamma^3\delta_{t+3} At(4)​=δt​+γδt+1​+γ2δt+2​+γ3δt+3​

代入：

AtGAE=(1−λ)[At(1)+λAt(2)+λ2At(3)+λ3At(4)+⋯ ]A_t^{GAE} = (1-\lambda) \left[ A_t^{(1)} + \lambda A_t^{(2)} + \lambda^2 A_t^{(3)} + \lambda^3 A_t^{(4)} + \cdots \right] AtGAE​=(1−λ)[At(1)​+λAt(2)​+λ2At(3)​+λ3At(4)​+⋯]

AtGAE=(1−λ)[δt+λ(δt+γδt+1)+λ2(δt+γδt+1+γ2δt+2)+λ3(δt+γδt+1+γ2δt+2+γ3δt+3)+⋯ ]A_t^{GAE} = (1-\lambda) \left[ \delta_t + \lambda(\delta_t + \gamma\delta_{t+1}) + \lambda^2(\delta_t + \gamma\delta_{t+1} + \gamma^2\delta_{t+2}) + \lambda^3(\delta_t + \gamma\delta_{t+1} + \gamma^2\delta_{t+2} + \gamma^3\delta_{t+3}) + \cdots \right] AtGAE​=(1−λ)[δt​+λ(δt​+γδt+1​)+λ2(δt​+γδt+1​+γ2δt+2​)+λ3(δt​+γδt+1​+γ2δt+2​+γ3δt+3​)+⋯]
